# LuBeam — Downloads

Public installers for **LuBeam**, a state-of-the-art PDF annotation,
measurement and data app for macOS and Windows.

The source code lives in a private repository; this repository exists
only to distribute builds.

## Latest release

**→ [Download LuBeam](https://github.com/hcarta/LuBeam-releases/releases/latest)**

| Platform | File | Install |
|---|---|---|
| macOS (Apple silicon + Intel) | `LuBeam.dmg` | Open the DMG and drag **LuBeam** into Applications |
| Windows 10/11 (x64) | `LuBeam-win-x64.zip` | Unzip and run `Install.cmd` — or just `LuBeam.exe` (WebView2 runtime required) |

Every version is published here when it is released — the link above always
points at the newest one. Release pages list the individual files.
